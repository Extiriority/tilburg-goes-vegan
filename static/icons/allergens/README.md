# Erudus allergen icons

Source: https://github.com/Erudus/erudus-icons/tree/master/src/svg

Copyright (c) 2016 Erudus Ltd. Used under the MIT license; see LICENSE.txt.
The 14 plain SVG files are retained unmodified and served locally. CSS masks
apply the surrounding text color. `soya.svg` maps to soy; `so2.svg` maps to
sulphites. Icons are decorative alongside localized allergen labels.

`coconut.svg` is a project-authored supplementary icon, not part of the Erudus set.
